Assignment name  : ft_range
Turn-in directory: ex01/
Expected files   : ft_range.c
Allowed functions: malloc
--------------------------------------------------------------------------------

• Create a functionft_range which returns an array ofints. Thisint array should
contain all values betweenmin and max.
• Min included -max excluded.
• Here is how it should be prototyped :
int *ft_range(int min, int max);
• If the value of min is greater than or equal to max, a NULL pointer should be
returned.

Your function must be declared as follows:
    int *ft_range(int min, int max);

Examples:
    int *a=ft_range(2,6); for(int i=0;i<4;i++) printf("%d ",a[i]); printf("\n"); free(a)
    Output: 2 3 4 5
