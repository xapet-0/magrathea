• Create a function that returns the result of converting the stringnbr from base
base_from to basebase_to.
• nbr, base_from, andbase_to may be read-only.
• nbr will follow the same rules asft_atoi_base (from another module). Beware of
the characters ’+’, ’-’, and whitespaces.
• The number represented bynbr must fit inside anint.
• If a base is invalid,NULL should be returned.
• The returned number must be prefixed only by a single and unique ’-’ if necessary;
no whitespaces, no ’+’.
• Here is how it should be prototyped:
char *ft_convert_base(char *nbr, char *base_from, char *base_to);
