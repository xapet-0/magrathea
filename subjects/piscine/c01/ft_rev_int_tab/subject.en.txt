Assignment name  : ft_rev_int_tab
Turn-in directory: ex07/
Expected files   : ft_rev_int_tab.c
Allowed functions: None
--------------------------------------------------------------------------------

• Create a function that reverses a given array of integers (the first element becomes
the last, and so on).
• The function takes two arguments: a pointer to an int and the number of elements
in the array.
• The function should be prototyped as follows:
void ft_rev_int_tab(int *tab, int size);

Your function must be declared as follows:
    void ft_rev_int_tab(int *tab, int size);

Examples:
    int t[] = {1,2,3,4,5}; ft_rev_int_tab(t, 5); for(int i=0;i<5;i++) printf("%d ", t[i]); printf("\n")
    Output: 5 4 3 2 1
