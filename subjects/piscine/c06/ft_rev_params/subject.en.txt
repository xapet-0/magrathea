• Since this is a program, your .c file must contain amain function.
• Write a program that displays its given arguments.
• Each argument should be printed on a new line, in the reverse order from the
command line.
• The program should display all arguments exceptargv[0].

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./ft_rev_params "one" "two" "three" | cat -e
three$
two$
one$
$> ./ft_rev_params "42" | cat -e
42$
$> ./ft_rev_params | cat -e
$
$> ./ft_rev_params "a" "b" "c" "d" | cat -e
d$
c$
b$
a$
