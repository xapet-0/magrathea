--------------------------------------------------------------------------------

Write a function that returns the integer square root of `nb` if it is a
perfect square, or `0` if `nb <= 0` or its square root is irrational.

Your function must be declared as follows:

int	ft_sqrt(int nb);

Examples:
ft_sqrt(0)  -> 0
ft_sqrt(1)  -> 1
ft_sqrt(4)  -> 2
ft_sqrt(9)  -> 3
ft_sqrt(15) -> 0
ft_sqrt(16) -> 4
ft_sqrt(-4) -> 0
