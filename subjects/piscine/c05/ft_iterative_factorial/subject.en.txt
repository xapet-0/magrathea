• Create an iterative function that returns a number. This number should be the
result of a factorial operation based on the given parameter.
• If the argument is not valid, the function should return 0.
• Overflows do not need to be handled; the function’s return value will be undefined
in such cases.
• The function should be prototyped as follows:
int ft_iterative_factorial(int nb);

Your function must be declared as follows:
    int ft_iterative_factorial(int nb);

Examples:
    ft_iterative_factorial(-1) -> 0
    ft_iterative_factorial(0) -> 1
    ft_iterative_factorial(5) -> 120
    ft_iterative_factorial(0) -> 1
