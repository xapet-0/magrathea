• Create a function that returns 1 if the given number is a prime number and 0 if it
is not.
• The function should be prototyped as follows:
int ft_is_prime(int nb);
0 and 1 are not prime numbers.

Your function must be declared as follows:
    int ft_is_prime(int nb);

Examples:
    ft_is_prime(-42) -> 0
    ft_is_prime(0) -> 0
    ft_is_prime(1) -> 0
    ft_is_prime(2) -> 1
