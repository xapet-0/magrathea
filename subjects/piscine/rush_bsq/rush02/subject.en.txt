• Create a program rush-02 that takes a number as argument and converts it to its
  written letters value using numbers.dict (or a custom dictionary when 2 arguments
  are passed: ./rush-02 <dict> <number>).
• Must handle numbers larger than unsigned int (up to 10^36 undecillion).
• If the argument is not a valid non-negative number, display "Error\n".
• If the dictionary has a parsing error or cannot resolve the number, display "Dict Error\n".
