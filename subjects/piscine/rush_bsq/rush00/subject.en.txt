Assignment name  : rush00
Turn-in directory: ex00/
Expected files   : main.c ft_putchar.c rush00.c
Allowed functions: write
--------------------------------------------------------------------------------

• Write a function rush(int x, int y) that displays a rectangle of width x and
  height y on screen.
  void rush(int x, int y);
• The team assignment (rush00 to rush04) is calculated from the first two letters
  of the team leader's login in base 26 modulo 5.
• If x <= 0 or y <= 0, the function displays nothing.
• Corner/Edge specification:
  - rush00: corners 'o', horizontal '-', vertical '|'
  - rush01: top-left '/', top-right '\', bottom-left '\', bottom-right '/', edges '*'
  - rush02: top corners 'A', bottom corners 'C', edges 'B'
  - rush03: left corners 'A', right corners 'C', edges 'B'
  - rush04: top-left 'A', top-right 'C', bottom-left 'C', bottom-right 'A', edges 'B'

Examples (rush00):
- rush(5, 3):
$> ./a.out
o---o
|   |
o---o
$>
- rush(5, 1):
$> ./a.out
o---o
$>
- rush(1, 1):
$> ./a.out
o
$>
- rush(1, 5):
$> ./a.out
o
|
|
|
o
$>
- rush(4, 4):
$> ./a.out
o--o
|  |
|  |
o--o
