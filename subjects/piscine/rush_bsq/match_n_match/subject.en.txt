Assignment name  : match_n_match
Expected files   : match_n_match.c
Allowed functions: None
--------------------------------------------------------------------------------

• Implement the functions `match` and `nmatch` in `match_n_match.c`:
  - `match(s1, s2)` returns 1 if `s1` and `s2` match, and 0 otherwise.
  - `nmatch(s1, s2)` returns the number of different ways `s1` and `s2` match.
• In `s2`, the character `*` can replace any character sequence (including the empty
  string). Multiple `*` characters may appear in `s2`.

Your functions must be declared as follows:
    int match(char *s1, char *s2);
    int nmatch(char *s1, char *s2);
