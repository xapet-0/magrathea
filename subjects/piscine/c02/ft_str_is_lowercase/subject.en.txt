• Create a function that returns 1 if the given string contains only lowercase alpha-
betical characters and 0 if it contains any other character.
• Here is how it should be prototyped:
int ft_str_is_lowercase(char *str);
• It should return 1 ifstr is empty.

Your function must be declared as follows:
    int ft_str_is_lowercase(char *str);

Examples:
    ft_str_is_lowercase("abc") -> 1
    ft_str_is_lowercase("abC") -> 0
    ft_str_is_lowercase("") -> 1
