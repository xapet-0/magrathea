Assignment name  : ft_boolean.h
Turn-in directory: ex01/
Expected files   : ft_boolean.h
Allowed functions: None
--------------------------------------------------------------------------------

• Create a ft_boolean.h file. It will compile and run the following main appropri-
ately:
#include "ft_boolean.h"
void ft_putstr(char *str);
{
while (*str)
write(1, str++, 1);
}
t_bool ft_is_even( int nbr)
{
return ((EVEN(nbr)) ? TRUE : FALSE);
}
int main(int argc, char **argv)
{
(void)argv;
if (ft_is_even(argc - 1) == TRUE)
ft_putstr(EVEN_MSG);
else
ft_putstr(ODD_MSG);
return (SUCCESS);
}
• This program should display:
I have an even number of arguments.
• or:
I have an odd number of arguments.
• followed by a line break when appropriate.
Norminette must be launched with the -R CheckDefine flag.
Moulinette will use it too.

Examples:
$> ./ft_boolean.h | cat -e
$
