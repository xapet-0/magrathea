Assignment name  : ft_print_combn
Turn-in directory: ex08/
Expected files   : ft_print_combn.c
Allowed functions: write
--------------------------------------------------------------------------------

• Create a function that displays all different combinations of n numbers in ascending order.
• n will be so that : 0 < n < 10.
• The function should be prototyped as follows:
void ft_print_combn(int n);

Examples:
    ft_print_combn(2)
    Output: 01, 02, 03, ..., 09, 12, ..., 79, 89
