Assignment name  : ft_print_comb2
Turn-in directory: ex06/
Expected files   : ft_print_comb2.c
Allowed functions: write
--------------------------------------------------------------------------------

• Create a function that displays all different combinations of two distinct two-digit
numbers (XX XX) between 00 and 99, listed in ascending order.
• The function should be prototyped as follows:
void ft_print_comb2(void);

Examples:
    ft_print_comb2()
    Output: 00 01, 00 02, 00 03, 00 04, 00 05, ..., 00 99, 01 02, ..., 97 99, 98 99
