Assignment name  : ft_searchinsert
Expected files   : ft_searchinsert.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a function that takes:
- a sorted array of distinct integers,
- the size of the array,
- and a target value.

The function must write:
- the index of the target if it is found in the array,
- otherwise, the index where the target should be inserted in order to keep the array sorted.

The output must be written to the standard output without a trailing newline.

Prototype:
void	ft_searchinsert(int *arr, int n, int target);

Examples:
int arr[] = {1, 3, 5, 6};

ft_searchinsert(arr, 4, 5);
// writes: 2

ft_searchinsert(arr, 4, 2);
// writes: 1

ft_searchinsert(arr, 4, 7);
// writes: 4

ft_searchinsert(arr, 4, 0);
// writes: 0
