Assignment name  : longest_sequence
Expected files   : longest_sequence.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that returns the length of the longest consecutive increasing
path (where child->value == parent->value + 1) in a binary tree.

Prototype:
int	longest_sequence(struct s_node *node);

Required structure / declarations:
#ifndef S_NODE_H
# define S_NODE_H
struct s_node
{
    int           value;
    struct s_node *left;
    struct s_node *right;
};
#endif

Your function must be declared as follows:
    int longest_sequence(struct s_node *node);

Examples:
    longest_sequence(NULL) -> 0
    longest_sequence(&a) -> 1
    longest_sequence(&a) -> 3
