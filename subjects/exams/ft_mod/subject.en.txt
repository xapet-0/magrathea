Assignment name  : ft_mod
Expected files   : ft_mod.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that returns the modulo of two integer numbers (n1 % n2):
    - if n2 is 0, return 0;

Your function must be declared as follows:

    int ft_mod(int n1, int n2);

Examples:
    ft_mod(10, 3) -> 1
    ft_mod(-7, 3) -> -1
    ft_mod(7, 0) -> 0
