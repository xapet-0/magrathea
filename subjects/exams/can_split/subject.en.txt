Assignment name  : can_split
Expected files   : can_split.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that takes the root of a binary tree and returns 1 if removing
a single edge can split the tree into two trees with an equal number of nodes,
or 0 otherwise.

Prototype:
int	can_split(struct s_node *n);

Required structure / declarations:
#ifndef S_NODE_H
# define S_NODE_H
struct s_node
{
    int           value;
    struct s_node *left;
    struct s_node *right;
};
#endif

Your function must be declared as follows:
    int can_split(struct s_node *n);

Examples:
    can_split(&n2) -> 1
    can_split(&n3) -> 0
    can_split(&n4) -> 1
