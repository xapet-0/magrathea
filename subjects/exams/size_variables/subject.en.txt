Assignment name  : size_variables
Expected files   : size_variable.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that displays the size of C variable types followed by a newline ('\n').

    - If the number of arguments is not 1, display only a newline.
    - If the argument is not one of ('int', 'char', 'float', 'double'), display only a newline.

Examples:
$> ./size_variables 'int' | cat -e
4 bytes$
$> ./size_variables 'char' | cat -e
1 bytes$
$> ./size_variables 'float' | cat -e
4 bytes$
$> ./size_variables 'double' | cat -e
8 bytes$
$> ./size_variables 'tryu' | cat -e
$
$> ./size_variables "" | cat -e
$
