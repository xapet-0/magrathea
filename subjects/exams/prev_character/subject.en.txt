Assignment name  : prev_character
Expected files   : prev_character.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a single character as argument and displays the
previous ASCII character followed by a newline ('\n'), wrapping 'a' to 'z' and
'A' to 'Z'.

If the number of arguments is not 1, or if the argument does not have length 1,
display only a newline.

Examples:
$> ./prev_character 'b' | cat -e
a$
$> ./prev_character 'a' | cat -e
z$
$> ./prev_character 'A' | cat -e
Z$
$> ./prev_character | cat -e
$
