Assignment name  : polyset
Expected files   : polyset.c
Allowed functions: write, malloc, free, printf
--------------------------------------------------------------------------------

Write a program that takes zero or more string arguments and displays the
unique arguments on standard output in first-seen order, separated by a single
space, followed by a newline.

If no arguments are given, the program displays only a newline.

Examples:
$> ./polyset 42 1337 42 | cat -e
42 1337$
$> ./polyset 42 | cat -e
42$
$> ./polyset 7 7 7 | cat -e
7$
$> ./polyset 1 2 3 2 1 | cat -e
1 2 3$
$> ./polyset | cat -e
$
