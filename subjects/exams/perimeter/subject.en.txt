Assignment name  : perimeter
Expected files   : perimeter.c
Allowed functions: printf
--------------------------------------------------------------------------------

Write a function that prints the perimeter (boundary) of a binary tree in
anti-clockwise order: root, left boundary top-down, all leaf nodes left-to-right,
and right boundary bottom-up, separated by single spaces and ending with a newline.

Prototype:
void	perimeter(struct s_node *root);

Required structure / declarations:
#ifndef S_NODE_H
# define S_NODE_H
struct s_node
{
    int           value;
    struct s_node *left;
    struct s_node *right;
};
#endif

Your function must be declared as follows:
    void perimeter(struct s_node *root);

Examples:
    struct s_node r={92,0,0}; perimeter(&r)
    Output: 92
    perimeter(NULL)
    Output: 
    struct s_node l={10,0,0}, r={20,0,0}, root={92,&l,&r}; perimeter(&root)
    Output: 92 10 20
