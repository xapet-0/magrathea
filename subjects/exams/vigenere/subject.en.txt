Assignment name  : vigenere
Expected files   : vigenere.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that encrypts a string using the Vigenere cipher.
The program takes exactly two arguments: the string to encrypt and the key.
- a or A -> shift by 0, b or B -> shift by 1, ..., z or Z -> shift by 25.
- Preserve the case of letters.
- Non-alphabetic characters are printed unchanged and DO NOT consume a character from the key.
- If the number of arguments is different from 3 (argc != 3), display only a newline.

Examples:
$> ./vigenere "hello" "abc"
hfnlp
$> ./vigenere "Hello World!" "abc"
Hfnlp Yosnd!
$> ./vigenere "A-B-C" "bc"
B-D-D
$> ./vigenere "attack at dawn!" "lemon"
lxfopv ef rnhr!
