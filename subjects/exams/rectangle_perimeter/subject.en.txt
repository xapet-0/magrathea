Assignment name  : rectangle_perimeter
Expected files   : rectangle_perimeter.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to calculate the perimeter of a rectangle:
    - mathematical formula for rectangle perimeter: (2 * width) + (2 * height).
    - if width or height is less than or equal to 0, return 0.

Your function must be declared as follows:
    int rectangle_perimeter(int width, int height);

Examples:
    rectangle_perimeter(5, 10) -> 30
    rectangle_perimeter(3, 4) -> 14
    rectangle_perimeter(0, 5) -> 0
