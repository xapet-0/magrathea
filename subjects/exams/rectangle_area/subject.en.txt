Assignment name  : rectangle_area
Expected files   : rectangle_area.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to calculate the area of a rectangle:
    - mathematical formula for the area of a rectangle: length * width.
    - if length or width is less than or equal to 0, return 0.

Your function must be declared as follows:
    int rectangle_area(int length, int width);

Examples:
    rectangle_area(1, 3) -> 3
    rectangle_area(12, 3) -> 36
    rectangle_area(0, 3) -> 0
