Assignment name  : sum_n
Expected files   : sum_n.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that takes an integer n as an argument and returns the sum of
all positive integers from 1 up to n inclusive. If n <= 0, return 0.

Your function must be declared as follows:
    int sum_n(int n);

Examples:
    sum_n(3) -> 6
    sum_n(21) -> 231
    sum_n(0) -> 0
