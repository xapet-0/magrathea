Assignment name  : remove_duplicate
Expected files   : remove_duplicate.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it without duplicate characters,
preserving the order of first appearance, followed by a newline.

If the number of arguments is not 1, the program displays only a newline.

Examples:
$> ./remove_duplicate "abracadabra" | cat -e
abrcd$
$> ./remove_duplicate "zazaza" | cat -e
za$
$> ./remove_duplicate | cat -e
$
