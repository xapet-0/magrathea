Assignment name  : infin_mult
Expected files   : infin_mult.c
Allowed functions: write, malloc, free
--------------------------------------------------------------------------------

Write a program that takes two arbitrary-precision integers as strings and
displays their product followed by a newline. Both positive and negative numbers
must be handled.

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./infin_mult "879879087" "67548976597" | cat -e
59434931855952726939$
$> ./infin_mult "9999999999" "0" | cat -e
0$
$> ./infin_mult "-6" "7" | cat -e
-42$
$> ./infin_mult "-6" "-7" | cat -e
42$
