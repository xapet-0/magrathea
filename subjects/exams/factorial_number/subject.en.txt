Assignment name  : factorial_number
Expected files   : factorial_number.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to compute the factorial of an integer.
If num < 0, return 0.

Your function must be declared as follows:
    int     factorial_number(int num);

Examples:
    factorial_number(5) -> 120
    factorial_number(2) -> 2
    factorial_number(0) -> 1
    factorial_number(-1) -> 0
