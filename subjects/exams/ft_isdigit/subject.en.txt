Assignment name  : ft_isdigit
Expected files   : ft_isdigit.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that checks if a character is a digit (0-9).

    With:
        - ASCII code of '0' is 48
        - ASCII code of '9' is 57

Your function must be declared as follows:

int ft_isdigit(int c);

Examples:
    ft_isdigit('0') -> 1
    ft_isdigit('9') -> 1
    ft_isdigit('a') -> 0
