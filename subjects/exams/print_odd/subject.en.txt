Assignment name  : print_odd
Expected files   : print_odd.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string argument and displays only the characters
whose index is not a multiple of 2, followed by a newline.
If the number of arguments is not 1, display only a newline.

Examples:
$> ./print_odd "FOR 42" | cat -e
O 2$
$> ./print_odd | cat -e
$
