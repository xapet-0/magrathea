Assignment name  : ft_sum_digits
Expected files   : ft_sum_digits.c
Allowed functions: write
--------------------------------------------------------------------------------

Code-only imported exam exercise.

Write a function that prints the repeated sum of the decimal digits of nbr, followed by a newline.
For example, 1337 becomes 1 + 3 + 3 + 7 = 14, then 1 + 4 = 5, so the output is 5.

Prototype:


void ft_sum_digits(int nbr);

Expected file: ft_sum_digits.c.

Examples:
  ft_sum_digits(1337) -> prints "5\n"   (1 + 3 + 3 + 7 = 14, then 1 + 4 = 5)
  ft_sum_digits(9999) -> prints "9
"   (9 + 9 + 9 + 9 = 36, then 3 + 6 = 9)
ft_sum_digits(10)   -> prints "1
"
ft_sum_digits(0)    -> prints "0
"
ft_sum_digits(2147483647) -> prints "1
"
ft_sum_digits(-2147483648) -> prints "2
"
