Assignment name  : ft_dec
Expected files   : ft_dec.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that takes a pointer to int and decrements its value.

Your function must be declared as follows:

void	ft_dec(int *ptr);

Examples:
    int x = 43; ft_dec(&x); -> x == 42
    int x = 0; ft_dec(&x); -> x == -1
