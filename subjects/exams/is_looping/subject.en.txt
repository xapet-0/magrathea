Assignment name  : is_looping
Expected files   : is_looping.c
Allowed functions: None
--------------------------------------------------------------------------------

ALERT: OPTIMIZED SOLUTION REQUIRED.

Given the first node of a singly linked list as parameter, create a function
which returns 1 if the linked list is looping (contains a cycle), otherwise 0.

The linked list uses the following structure:

struct s_node {
	int value;
	struct s_node *next;
};

Your function must be declared as follows:

int	is_looping(struct s_node *node);

Note: An optimal O(N) time and O(1) auxiliary space solution (Floyd's tortoise
and hare cycle-finding algorithm) is required because the input list can contain
more than 500,000 nodes and values in nodes are not distinct.

Example 1:
1 -> 2 -> 3 -> 4 -> 5
          ^         |
          |         v
          7 <- 6 <- *
Returns: 1

Example 2:
12 -> 150 -> 30 -> 50 -> 345 -> 120 -> 200 -> NULL
Returns: 0

Example 3:
12 -> 150 -> 30 -> 50 -> 345 -> 120
       ^                         |
       |                         v
       * <- 200 <- 220 <- 100 <- *
Returns: 1

Example 4:
12 -> 19 -> 14 -> NULL
Returns: 0

Example 5 (Self-loop on single node):
42 -> 42 (node->next == node)
Returns: 1
