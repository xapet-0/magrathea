Assignment name  : nth_char
Expected files   : nth_char.c
Allowed functions: write, atoi
--------------------------------------------------------------------------------

Write a program that takes a string and a positive integer N, and prints every
Nth character of the string, followed by a newline.

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./nth_char "abcdef" "2" | cat -e
bdf$
$> ./nth_char "42" "1" | cat -e
42$
$> ./nth_char "123456" "3" | cat -e
36$
$> ./nth_char | cat -e
$
