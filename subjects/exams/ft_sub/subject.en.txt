Assignment name  : ft_sub
Expected files   : ft_sub.c
Allowed functions: None
--------------------------------------------------------------------------------

Create a function that subtracts an integer a from an integer pointed to by ptr.

Your function must be declared as follows:

void	ft_sub(int a, int *ptr);

Examples:
    int x = 50; ft_sub(8, &x); -> x == 42
    int x = -5; ft_sub(5, &x); -> x == -10
