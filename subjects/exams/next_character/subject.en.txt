Assignment name  : next_character
Expected files   : next_character.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that displays the next ASCII character followed by a newline
('\n'), wrapping 'z' to 'a' and 'Z' to 'A'.

If the number of arguments is not 1, or if the argument is empty, display only
a newline.

Examples:
$> ./next_character 'A' | cat -e
B$
$> ./next_character 'z' | cat -e
a$
$> ./next_character | cat -e
$
$> ./next_character "" | cat -e
$
