Assignment name  : argo
Expected files   : argo.c
Allowed functions: getc, ungetc, printf, malloc, calloc, realloc, free, isdigit, fscanf, write
--------------------------------------------------------------------------------

Write a program that reads JSON from standard input, validates it, and prints
the compacted JSON followed by a newline on standard output.

Only handle numbers, strings, and maps (objects):
- Numbers are basic signed integers parsed like scanf("%d").
- Inside strings, handle escaping only for backslashes (\\) and quotation marks (\").
- Ignore whitespace characters (' ', '\t', '\n', '\r') outside strings.
- If an unexpected token is encountered, print on standard output:
  "Unexpected token '%c'\n"
  and exit with status 1.
- If EOF is reached unexpectedly, print on standard output:
  "Unexpected end of input\n"
  and exit with status 1.

Examples:
$> echo -n '1' | ./argo | cat -e
1$
$> echo -n '"bonjour"' | ./argo | cat -e
"bonjour"$
$> echo -n '"escape! \" "' | ./argo | cat -e
"escape! \" "$
$> echo -n '{"tomatoes":42,"potatoes":234}' | ./argo | cat -e
{"tomatoes":42,"potatoes":234}$
$> echo -n '{"recursion":{"recursion":{"recursion":{"recursion":"recursion"}}}}' | ./argo | cat -e
{"recursion":{"recursion":{"recursion":{"recursion":"recursion"}}}}$
$> echo -n '"unfinished string' | ./argo | cat -e
Unexpected end of input$
$> echo -n '"unfinished string 2\"' | ./argo | cat -e
Unexpected end of input$
$> echo -n '{"no value?":}' | ./argo | cat -e
Unexpected token '}'$
