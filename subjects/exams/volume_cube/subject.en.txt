Assignment name  : volume_cube
Expected files   : volume_cube.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to find the volume of a cube:
    - mathematical formula of cube volume: side ^ 3.
    - if side is less than or equal to 0, return 0.

Your function must be declared as follows:
    int volume_cube(int side);

Examples:
    volume_cube(3) -> 27
    volume_cube(0) -> 0
