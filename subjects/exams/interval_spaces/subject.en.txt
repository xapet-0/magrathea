Assignment name  : interval_spaces
Expected files   : interval_spaces.c
Allowed functions: write
--------------------------------------------------------------------------------

Create a program that writes three spaces between each character in a string argument.

If the number of arguments is different from 1, the program prints only a newline.

Examples:
$> ./interval_spaces "abc" | cat -e
a   b   c$
$> ./interval_spaces "dubO a POIL" "ok" | cat -e
$
