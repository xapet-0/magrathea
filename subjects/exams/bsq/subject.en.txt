Assignment name  : bsq
Expected files   : bsq.c
Allowed functions: open, read, write, close, malloc, free, exit
--------------------------------------------------------------------------------

The aim of this program is to find the biggest square on a map, avoiding obstacles.
A file containing the map will be provided as an argument for your program.
The first line of the map contains information on how to read the map (compact, with no spaces):
 - The number of lines on the map;
 - The "empty" character;
 - The "obstacle" character;
 - The "full" character.
The map is made up of "empty" characters, lines and "obstacle" characters.
The aim of the program is to replace "empty" characters by "full" characters in
order to represent the biggest square possible.
In the case that more than one solution exists, choose the square closest to
the top of the map, then the one most to the left.
When your program receives more than one map as arguments, each solution or
"map error" must be separated by an empty line.
Should there be no passed arguments, your program must read from standard input.

Definition of a valid map:
 - All lines must have the same length.
 - There is at least one line of at least one box.
 - At each end of line, there is a line break.
 - The characters on the map can only be those introduced in the first line.
 - The map is invalid if a character is missing from the first line, or if any two characters (empty, obstacle, full) are identical.
 - The characters can be any printable character, even numbers.
 - In case of an invalid map, your program must display "map error" on standard error followed by a newline, and move on to the next map.
