Assignment name  : ft_inc
Expected files   : ft_inc.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that takes a pointer to int and increments its value.

Your function must be declared as follows:

void	ft_inc(int *ptr);

Examples:
    int x = 41; ft_inc(&x); -> x == 42
    int x = -1; ft_inc(&x); -> x == 0
