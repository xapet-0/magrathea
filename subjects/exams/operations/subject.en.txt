Assignment name  : operations
Expected files   : operations.c
Allowed functions: atoi, printf, write
--------------------------------------------------------------------------------

Write a program that takes two integers as arguments and prints their sum,
difference, product, quotient, and remainder, or handles arithmetic operations
like do_op.

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./operations "40" "+" "2" | cat -e
42$
$> ./operations "50" "-" "8" | cat -e
42$
$> ./operations "6" "*" "7" | cat -e
42$
$> ./operations | cat -e
$
