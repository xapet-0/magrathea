Assignment name  : inter_space
Expected files   : inter_space.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and displays, without doubles, the
characters that appear in both strings, in the order they appear in the first
one, separated by a single space and followed by a newline.

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./inter_space "padinton" "paqefwtdjetyiytjneytjoeyjnejeyj" | cat -e
p a d i n t o$
$> ./inter_space "abc" "bcd" | cat -e
b c$
$> ./inter_space "a" "a" | cat -e
a$
$> ./inter_space | cat -e
$
