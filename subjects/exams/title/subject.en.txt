Assignment name  : title
Expected files   : title.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes 1 string argument and converts the first character
of each word (if it is a lowercase letter) to uppercase, followed by a \n.

A word is a section of string delimited by spaces/tabs or the start/end of the
string. If a word has a single letter, it must be capitalized.

If the number of arguments is not 1, display \n.

Examples:
$> ./title | cat -e
$
$> ./title "no NO no no no!" | cat -e
No NO No No No!$
$> ./title pjldfjslogjlsj | cat -e
Pjldfjslogjlsj$
