Assignment name  : print_nth_char
Expected files   : print_nth_char.c
Allowed functions: write
--------------------------------------------------------------------------------

Write the following function:


void print_nth_char(char *str, int n);

The function prints every nth character of str, followed by a newline. Counting is 1-based: with n = 2, it prints characters at positions 2, 4, 6, and so on.

If n <= 0, if str is empty, or if n is greater than the string length, print only a newline.

Examples: ABCDEF, 2 -> BDF; Hello, 2 -> el.

Allowed functions: write.
