Assignment name  : height_tree
Expected files   : height_tree.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that returns the height (maximum number of edges from root to a
leaf) of an n-ary tree. An empty tree has height -1; a single node has height 0.

Prototype:
int	height_tree(struct s_node *root);

Required structure / declarations:
struct s_node { int value; struct s_node **nodes; };

Your function must be declared as follows:
    int height_tree(struct s_node *root);

Examples:
    height_tree(NULL) -> -1
    height_tree(&r) -> 0
    height_tree(&r) -> 1
