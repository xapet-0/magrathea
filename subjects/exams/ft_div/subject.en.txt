Assignment name  : ft_div
Expected files   : ft_div.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that divides the integer a by the integer b and returns the
result.
    - If b is 0, return 0.

Your function must be declared as follows:
    int ft_div(int a, int b);

Examples:
    ft_div(20, 5) -> 4
    ft_div(7, 0) -> 0
    ft_div(42, 0) -> 0
    ft_div(-84, 2) -> -42
