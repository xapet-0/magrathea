Assignment name  : is_consonant
Expected files   : is_consonant.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that checks if a character is an English consonant letter.
Non-alphabetical characters and vowels must return 0.

Your function must be declared as follows:
    int is_consonant(char c);

Examples:
    is_consonant('b') -> 1
    is_consonant('C') -> 1
    is_consonant('o') -> 0
    is_consonant('A') -> 0
    is_consonant('z') -> 1
    is_consonant('1') -> 0
