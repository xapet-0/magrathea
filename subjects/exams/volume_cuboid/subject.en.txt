Assignment name  : volume_cuboid
Expected files   : volume_cuboid.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to find the volume of a cuboid:
    - mathematical formula of cuboid volume: length * width * height.
    - if any dimension is less than or equal to 0, return 0.

Your function must be declared as follows:
    int volume_cuboid(int length, int width, int height);

Examples:
    volume_cuboid(2, 3, 4) -> 24
    volume_cuboid(0, 3, 4) -> 0
