Assignment name  : longest_word
Expected files   : longest_word.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays the longest word in the string
followed by a newline. If several words have the same maximum length, print the
first one.

Requirements:
    - If the number of arguments is invalid, the program must display a newline (or the specified error message) and exit cleanly.
    - Your program will be compiled with: cc -Wall -Wextra -Werror.

Examples:
$> ./longest_word "hello 1337 coding school" | cat -e
coding$
$> ./longest_word "  piscine  " | cat -e
piscine$
$> ./longest_word "   " | cat -e
$
$> ./longest_word | cat -e
$
