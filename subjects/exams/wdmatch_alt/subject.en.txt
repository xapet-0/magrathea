Assignment name  : wdmatch_alt
Expected files   : wdmatch_alt.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes two strings and checks whether the first string can
be formed from characters in the second string while preserving their order.

If it can, display the first string followed by a newline. Otherwise, display
only a newline. If the number of arguments is not 2, display only a newline.

Examples:
$> ./wdmatch_alt "faya" "fgvvfdxcacpolhyghbreda" | cat -e
faya$
$> ./wdmatch_alt "faya" "fgvvfdxcacpolhyghbred" | cat -e
$
$> ./wdmatch_alt "quarante deux" "qfqfsudf arzgsayns tsregfdgs sjytdekuoixq " | cat -e
quarante deux$
$> ./wdmatch_alt | cat -e
$
