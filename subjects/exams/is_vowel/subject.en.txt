Assignment name  : is_vowel
Expected files   : is_vowel.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that checks if a character is an English vowel ('a', 'e', 'i',
'o', 'u', uppercase or lowercase).

Your function must be declared as follows:
    int is_vowel(char c);

Examples:
    is_vowel('a') -> 1
    is_vowel('U') -> 1
    is_vowel('P') -> 0
    is_vowel('z') -> 0
