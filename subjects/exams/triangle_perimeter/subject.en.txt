Assignment name  : triangle_perimeter
Expected files   : triangle_perimeter.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to calculate the perimeter of a triangle:
    - mathematical formula for the perimeter of a triangle: a + b + c,
      with a, b, and c as the sides of the triangle.
    - if any side is less than or equal to 0, return 0.

Your function must be declared as follows:
    int triangle_perimeter(int a, int b, int c);

Examples:
    triangle_perimeter(3, 4, 5) -> 12
    triangle_perimeter(10, 10, 10) -> 30
    triangle_perimeter(0, 4, 5) -> 0
