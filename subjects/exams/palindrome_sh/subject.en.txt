Assignment name  : palindrome_sh
Expected files   : palindrome_sh.sh
Allowed commands : printf, tr, rev
--------------------------------------------------------------------------------

Write a shell script that checks whether the string in $FT_LINE (or $1) is
a palindrome, printing 1 if it reads the same forward and backward, or 0
otherwise.

Requirements:
    - Your solution must be POSIX-compliant (/bin/sh) and handle spaces, tabs, and special characters safely.
    - Do not leave temporary files behind in the working directory.

Examples:
$> FT_LINE="kayak" sh palindrome_sh.sh | cat -e
1$
$> FT_LINE="hello" sh palindrome_sh.sh | cat -e
0$
$> FT_LINE="radar" sh palindrome_sh.sh | cat -e
1$
$> FT_LINE="1331" sh palindrome_sh.sh | cat -e
1$
