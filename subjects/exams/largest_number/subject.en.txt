Assignment name  : largest_number
Expected files   : largest_number.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function that takes 3 integer variables and returns the largest of them.

Your function must be declared as follows:
    int largest_number(int n1, int n2, int n3);

Examples:
    largest_number(3, 14, 96) -> 96
    largest_number(63, 14, 16) -> 63
