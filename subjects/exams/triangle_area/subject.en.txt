Assignment name  : triangle_area
Expected files   : triangle_area.c
Allowed functions: None
--------------------------------------------------------------------------------

Write a function to calculate the area of a triangle:
    - mathematical formula for the area of a triangle: (base * height) / 2.
    - if base or height is less than or equal to 0, return 0.

Your function must be declared as follows:
    int triangle_area(int base, int height);

Examples:
    triangle_area(2, 4) -> 4
    triangle_area(1, 2) -> 1
    triangle_area(0, 5) -> 0
